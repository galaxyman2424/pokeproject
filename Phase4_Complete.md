## Bug Fix — Type Chart Data Layer

### Problem

`typechart.json` was generated by `data/dump_data.js` using `Dex.types.effectiveness()` from `@pkmn/dex`, which does not exist in the installed version. Every value in the output was `1`, making all type effectiveness lookups return neutral multipliers regardless of actual type interactions. This caused Steel types to appear weak to Fire, Ghost types to appear weak to Dark, and all defensive profiles to be analytically useless.

A second attempt used `damageTaken` from the `@pkmn/dex` type objects directly. The raw encoded integers were inconsistent — both 2x weak and 0.5x resist matchups were encoded as `1` in different entries, making the encoding undecodable without external ground truth.

### Fix

`typechart.json` was deleted. The Gen 9 type chart was hardcoded directly into `pokemon_data.py` as a Python dict:

```python
TYPE_CHART[attacking_type][defending_type] = multiplier
```

Where multiplier is one of `0.0`, `0.5`, `1.0`, or `2.0`. `DAMAGE_TAKEN_MAP` and `load_typechart()` were removed entirely. `get_type_effectiveness()` was updated to read directly from `TYPE_CHART`.

## Module — threat_analysis.py

### Interface

```python
from analysis.threat_analysis import analyze_threats, print_report

report = analyze_threats(["Great Tusk", "Gholdengo", "Kingambit", "Dragonite", "Hatterene", "Corviknight"])
print_report(report)
```

### Functions

| Function | Description |
| :--- | :--- |
| `load_meta_threats(top_n)` | Loads top N Pokémon from `output/pokemon_usage.csv` with types and speed. Defaults to 20. Updates automatically when Phase 2 is re-run. |
| `load_speed_tiers(top_n)` | Same source, returns `{name: base_speed}` sorted descending. |
| `defensive_profile(pokemon_list)` | Sums type effectiveness multipliers across all 6 Pokémon for all 18 types. |
| `offensive_stab_coverage(pokemon_list)` | Returns the set of types the team has STAB on. |
| `find_type_holes(pokemon_list)` | Flags types where total team exposure exceeds threshold (default 8.0) and team has no STAB to retaliate. Sorted by severity. |
| `find_speed_gaps(pokemon_list)` | Returns max/min/avg base speed and which meta benchmarks outspeed the entire team. |
| `find_role_gaps(pokemon_list)` | Checks for missing hazard removal, missing Stealth Rock setter, weather abusers without a setter. |
| `meta_coverage_score(pokemon_list)` | For each top meta threat, checks whether the team has a STAB type that hits it. Returns score and list of uncovered threats. |
| `archetype_weakness_flags(pokemon_list)` | Rule-based flags for structural weakness to Rain, Sun, and Hyper Offense. |
| `threat_score(report)` | Collapses the full report into a single float penalty scalar in range 0.0–1.0 for Phase 5 fitness scoring. |
| `analyze_threats(pokemon_list)` | Single entry point — calls all of the above and returns one structured report dict. |
| `print_report(report)` | Pretty-prints the full report to terminal. |

### Design Decisions

- `META_THREATS` and `SPEED_TIERS` are loaded dynamically from `output/pokemon_usage.csv` at runtime so they stay current as more replays are ingested and Phase 2 is re-run.
- `WEATHER_SETTERS`, `ROCKS_SETTERS`, `HAZARD_REMOVERS`, `RAIN_ABUSERS`, `SUN_ABUSERS` are hardcoded as structural game knowledge that does not change with the dataset.
- `threat_score` weighted contributions: type holes (up to 0.3), meta coverage (up to 0.3), role gaps (up to 0.2), speed gaps (up to 0.1), archetype flags (up to 0.1).

---

## Threat Score Weights
threat_score = type_holes_penalty      (up to 0.30)
+ role_gaps_penalty       (up to 0.20)
+ meta_coverage_penalty   (up to 0.30)
+ archetype_flag_penalty  (up to 0.10)
+ speed_gap_penalty       (up to 0.10)

Lower is better. Range 0.0–1.0.

## Phase 4 Deliverable

A complete threat analysis engine that:

- Computes defensive exposure profiles across all 18 types for any team
- Identifies type holes where exposure is high and no STAB retaliation exists
- Flags missing team roles (hazard removal, Stealth Rock, weather support)
- Benchmarks team speed against the current metagame's top threats
- Scores meta coverage against the top 20 most-used Pokémon
- Detects structural archetype weaknesses (Rain, Sun, Hyper Offense)
- Collapses all findings into a single threat score scalar ready for Phase 5 fitness evaluation
- Validates correctly against known Gen 9 OU team archetypes
